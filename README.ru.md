# poe2-blackbox

«Чёрный ящик» для хардкора в Path of Exile 2. Работает на компьютере игрока, читает `Client.txt`
и записывает каждую смерть с контекстом: зона, уровень области, уровень персонажа, время в зоне,
моды вейстоуна, пинг до инстанс-сервера, снимок снаряжения и видеоклип последней минуты.

## Запуск из готовой сборки

Скачайте архив для своей системы из [релизов](https://github.com/MaxTor2001/poe2-blackbox/releases),
распакуйте и запустите `blackbox` (на Windows `blackbox.exe`). Без аргументов это команда `run`:
программа находит лог игры, начинает запись и открывает журнал в браузере по адресу
http://127.0.0.1:8765/. Если лог не найден, укажите путь: `blackbox run --log "C:\...\logs\Client.txt"`.

## Запуск из исходников

```
uv run blackbox run    --log /path/to/Client.txt   # всё в одном процессе, открывает журнал
uv run blackbox watch  --log /path/to/Client.txt   # только слежение за логом
uv run blackbox serve                              # только страница журнала
uv run blackbox import --log /path/to/Client.txt   # разобрать существующий лог один раз
uv run blackbox deaths                             # список смертей в терминале
uv run pytest
```

## Что собирается и как

- **События лога**: смены зон, генерация областей (уровень, сид), левелапы, смерти, подключения
  к инстанс-серверу. Всё из `Client.txt`, ничего другого из игры не читается.
- **Пинг**: TCP-соединение к текущему инстанс-серверу раз в 2 секунды; журнал показывает средний,
  максимальный и потерянные замеры за минуту до смерти.
- **Моды вейстоуна**: нажмите Ctrl+C на вейстоуне перед запуском карты; текст из буфера обмена
  разбирается и привязывается к смертям в этой карте.
- **Снимок снаряжения**: при входе в зону, не чаще раза в минуту, из окна персонажа на
  pathofexile.com. Сайт отвечает только вошедшим, поэтому один раз запустите с
  `--account "Имя#1234" --sessid <POESESSID>` (куки из браузера на pathofexile.com); оба значения
  запоминаются в `config.json` в папке данных, открытым текстом, только на вашей машине.
  Снимки хранятся как сырой JSON.
- **Клипы смертей**: экран пишется через ffmpeg короткими сегментами в папку `clips` рядом
  с базой, через несколько секунд после смерти последняя минута сохраняется в mp4 и появляется
  в журнале. В сборке для Windows ffmpeg упакован; на Linux нужен `ffmpeg` в PATH. Используется
  NVENC, если есть, иначе libx264 в 1080p. `--no-clips` отключает запись. Стримеры с OBS могут
  передать `watch --obs`, чтобы использовать его буфер повтора.

База, клипы и `blackbox.log` лежат в папке данных пользователя (`%APPDATA%\\poe2-blackbox` на Windows,
`~/.local/share/poe2-blackbox` на Linux), поэтому обновление программы не теряет историю. При первом
запуске существующий лог разбирается целиком, и прошлые смерти появляются сразу.

Все данные остаются на вашем компьютере. Ничего никуда не отправляется.

Этот продукт никак не связан с Grinding Gear Games и не одобрен ими.
